# Initiale Konfiguration der DHBW CAS Studienarbeit

In der Datei `vorlage.tex` befindet sich der Konfigurationsbereich für Deine persönliche Studienarbeit:

```tex
% -------------------------------------------------------
% Konfiguration der Studienarbeit (DHBW CAS)
% -------------------------------------------------------

\def\myTopic{Systematische Literaturübersicht und vergleichende Analyse von Methoden zur Evaluierung und Auswahl von COTS-Software}
\def\mySubTopic{}
\def\myAutor{Malik Jannico Press}
\def\myMatrikelnummer{1781283}
\def\myKurs{WMWI22}
\def\myProf{Prof. Dr. Frank Koslowski}
\def\myEndDate{30. November 2026}

% Optionale Angaben zum Dualen Partner
\def\myCompany{Vetter Pharma-Fertigung GmbH \& Co. KG}
\def\myCompanyAddressStreet{Schützenstraße 87}
\def\myCompanyAddressCity{88212 Ravensburg}
```

### Übersicht der Parameter

| Befehl | Erläuterung |
| --- | --- |
| `\def\myTopic{...}` | Titel der Studienarbeit |
| `\def\mySubTopic{...}` | Untertitel (falls vorhanden, sonst leer lassen) |
| `\def\myAutor{...}` | Name des Verfassers |
| `\def\myMatrikelnummer{...}` | Matrikelnummer |
| `\def\myKurs{...}` | Kursbezeichnung (z. B. WMWI22) |
| `\def\myProf{...}` | Akademischer Betreuer (z. B. Prof. Dr. Frank Koslowski) |
| `\def\myEndDate{...}` | Abgabedatum der Arbeit |
| `\def\myCompany{...}` | Name des Dualen Partners (optional) |
| `\def\myCompanyAddressStreet{...}` | Straße des Dualen Partners (optional) |
| `\def\myCompanyAddressCity{...}` | PLZ/Ort des Dualen Partners (optional) |

### Vorgaben und Rahmenbedingungen der DHBW CAS (Modul W3M20033)

- **Umfang:** 20 - 30 Seiten (reiner Text ohne Verzeichnisse, Deckblatt, Anhänge)
- **Bearbeitungszeit:** i.d.R. 6 Monate
- **Formale Vorgaben:**
  - Schriftart: Arial (11 pt)
  - Zeilenabstand: 1,5-zeilig (6 pt Absatzabstand nach)
  - Seitenränder: Oben 2,5 cm, Unten 2,5 cm, Links 4,0 cm, Rechts 3,0 cm
  - Kopfzeile: Nur zentrierte Seitenzahl (keine Autorennamen, Kapitel oder Trennlinien)
  - Reihenfolge: Deckblatt, Ehrenwörtliche Erklärung, Inhaltsverzeichnis (römische Seitenzahlen), Hauptteil (arabische Seitenzahlen ab S. 1), Literaturverzeichnis.
